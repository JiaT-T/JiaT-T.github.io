第一百三十九题：单词拆分#

1. 确定状态：dp[ i ] 代表前 i 个字符组成的字符串是否能够被拆分
2. 状态转移：dp[ i ] = (**dp[ j ]** && **s.substr(j, i - j)**也能够被拆分)，其中 j 为区间 [ 0, i ] 的任意整数

具体实现：

首先将字典转换为无序集合，提高查找速度；原字符串拷贝至string_view类型，以实现零开销访问范围内的部分字符串；最后定义dp数组，用来记录前 i 个字符能否被拆分，注意这里的首位元素为真，因为空字符串肯定是能够被拆分的，其他位默认为假

进入循环——外层循环遍历原字符串，内层循环遍历字典；之后根据上述的 b 条件，确定字符串前i个元素是否能拆分

 1bool wordBreak(string s, vector<string>& wordDict)
 2{
 3    std::unordered_set<string_view> dict(wordDict.begin(), wordDict.end());
 4    std::string_view sv = s;
 5    std::vector<bool> dp(s.size() + 1, false);
 6    dp[0] = true;
 7
 8    for(int i = 1; i <= s.size(); i++)
 9    {
10        for(int j = 0; j < i; j++)
11        {
12            if(dp[j] && dict.find(sv.substr(j, i - j)) != dict.end()) 
13            {
14                dp[i] = true;
15                break;
16            }
17        }
18    }
19    return dp[s.size()];
20}

第一百九十八题：打家劫舍#

1.状态定义：

dp[i]指的是”到达第i个房子时，目前为止能偷到的最大金额是多少“

2.转移方程：

用一个例子来解释——

假如当前已经偷完了前3栋房子，来到了第四栋房子（里面有num元）

那么现在就有两个选择：

1).不偷第四栋房子，那么金额就是dp[3]（也就是前三栋房子的最优结果）

2).偷第四栋房子，那么总金额就是dp[i-1] + num（前两栋房子的最优结果加上第四栋房子）

因此，前四栋房子的最大金额就是两者中的更大者

 1int rob(vector<int>& nums)
 2{
 3    int pre = 0, curr = 0;
 4    int temp;
 5    for(int num : nums)
 6    {
 7        temp = curr;
 8        curr = std::max(pre + num, curr);
 9        pre = temp;
10    }
11    return curr;
12}

第二百七十九题：完全平方数#

定义了一个数组，用来存储n之前每一个元素的完全平方数的最少数量，这样就得到了状态转移方程：

$ dp[i] = 1 + \min_{1 \le j^2 \le i} \{ dp[i - j^2] \} $

其中，i 是从1到 n 的所有数字，j^2是小于等于 i 的所有完全平方数

每次当 n 减去 i 之后，都会以 i 为右边界进行一次遍历，此时就是对每一个 i 进行”局部穷举“，看看此时有哪些组成 j^2 的最少数字数量，我们会选取最小的作为当前的结果

 1int numSquares(int n)
 2{
 3    std::vector<int> f(n + 1);
 4    for(int i = 1; i <= n; i++)
 5    {
 6        int minn = INT_MAX;
 7        for(int j = 1; j * j <= i; j++)
 8            minn = std::min(minn, f[i - j * j]);
 9        
10        f[i] = minn + 1;
11    }
12    return f[n];
13}

第三百题：最长递增子序列#

解法一：动态规划

状态定义：dp[ i ]指的是“以第 i 个元素结尾的子序列的最大长度”

状态转移：dp[ i ] = max( dp[ i ], dp[ j ] + 1 )，其中 j 是不大于 i 的正整数；

方程的意义是——假设正在处理 nums[i]，我们想把它接在一个现有的子序列后面。

为了保证“严格递增”，必须满足两个条件：

1. **位置在前后**：那个数必须在 i 之前（即 j < i）。
2. **数值从小到大**：那个数必须比 `nums[i]` 小（即 nums[j] < nums[i]）。

 1int lengthOfLIS(vector<int>& nums)
 2{
 3    if(nums.empty()) return 0;
 4    std::vector<int> dp(nums.size(), 1);
 5    int res = 1;
 6    for(int i = 0; i < nums.size(); i++)
 7    {
 8        for(int j = 0; j < i; j++)
 9        {
10            if(nums[j] < nums[i]) 
11            {
12                dp[i] = std::max(dp[i], dp[j] + 1);
13            }
14        }
15        res = std::max(res, dp[i]);
16    }
17    return res;
18}

补充解法：二分查找维护最小末尾

维护一个数组 dp，dp【i】的含义是：长度为 i + 1 的子数组的末尾元素的最小值

然后遍历数组 nums，在 dp 中通过二分查找，看看 num 的位置在哪里

  • 如果不存在任何一个数大于等于 num，也就是 it = num.end（），就将 num 接入 dp 的末尾，意味着子序列的长度可以加一
  • 如果当前数组中已经有一个数大于等于 num 了，就将这个数替换为 num（降低末尾元素的值，确保后续可以有更多元素加入）
  • 时间复杂度：O(n logn)，其中 n 为 nums 的长度
  • 空间复杂度：O(n)

 1int lengthOfLIS(vector<int>& nums)
 2{
 3    std::vector<int> dp;
 4
 5    for(int num : nums)
 6    {
 7        auto it = std::lower_bound(dp.begin(), dp.end(), num);
 8        if(it == dp.end())
 9        {
10            dp.push_back(num);
11        }
12        else
13        {
14            *it = num;
15        }
16    }
17    return dp.size();
18}

补充解法：原地修改

直接对传入的 nums 数组进行修改，避免再创建一个新数组

lengthOfLIS（）

 1int lengthOfLIS(vector<int>& nums)
 2{
 3    // 从第一个元素开始
 4    auto end = nums.begin();
 5
 6    for(int num : nums)
 7    {
 8        // 在区间内找到第一个大于等于 num 的位置
 9        auto it = lower_bound(nums.begin(), end, num);
10
11        // 将原来 g[j] 的值（一个较大的数）替换成更小的 num
12        // 为什么直接认为 num 一定小于之前的末尾元素？
13        /* 因为 lower_bound(first, last, x) 返回的是第一个满足 元素 >= x 的位置。
14        因此，当 it != end 时，*it >= x 恒成立。
15        于是执行 *it = x 后：
16        如果 *it > x，新值变小（这正是我们想要的，因为要降低该长度的最小末尾）。
17        如果 *it == x，新值不变（没有影响）。
18        没有可能出现 *it < x 的情况，所以不存在“当前元素大于原末尾”的问题*/
19        *it = num;
20
21        if(it == end)
22        {
23            // 此时将长度加一
24            end++;
25        }
26    }
27    return end - nums.begin();
28}

第三百二十二题：零钱兑换#

确定状态：dp[ i ]代表 为了凑出 i 元，所需要的硬币数量

状态转移：dp[ i ] = min(dp[ i ], dp[ i - coin ] + 1)，即金额 i 的最优解，必然是由某个较小的金额 i - coin 转移而来的。

 1int coinChange(vector<int>& coins, int amount)
 2{
 3    std::vector<int> dp(amount + 1, amount + 1);
 4    dp[0] = 0;
 5
 6    for(int i = 1; i <= amount; i++)
 7    {
 8        for(auto coin :coins)
 9        {
10            if(coin <= i)
11                dp[i] = std::min(dp[i], dp[i - coin] + 1);
12        }
13    }
14    return dp[amount] > amount ? -1 : dp[amount];
15}

第一百五十二题：乘积最大子数组#

确定状态：dp[ i ] 代表“以当前元素为结尾的最大/最小乘积是多少”

状态转移：（具体公式见下图）一开始的想法是——如果当前元素乘上dp数组的上一个元素之后，所得乘积比上一个还要小，那么就以当前元素为起点向后乘；反之，将所得乘积作为以当前元素（nums[ i ]）为结尾的连续乘积存入dp数组

但是这会导致一个问题——如果原数组是 [ -2, 3, -4 ] 这种类型的话，期望结果是24（因为负负得正），但是上一个方法却会直接抛弃-2 * 3的结果，转而从 -4 开始重新计数，又因为此时已经到达了末尾，此时dp数组为 [-2, -6, -4 ] 所以最后会返回-2

上一种方法相当于只记录了最大正乘积，没有考虑到最小负乘积可能会与负数相乘，因此还需要定义一个dp数组，用于存放最小乘积

 1int maxProduct(vector<int>& nums)
 2{
 3    if(nums.size() == 1) return nums[0];
 4    std::vector<int> dp_max(nums.size(), 1), dp_min(nums.size(), 1);
 5    dp_max[0] = dp_min[0] = nums[0];
 6
 7    int res = nums[0];
 8    for(int i = 1; i < nums.size(); i++)
 9    {
10        int choice1 = dp_max[i -1] * nums[i];
11        int choice2 = dp_min[i -1] * nums[i];
12        
13        dp_max[i] = std::max({nums[i], choice1, choice2});
14        dp_min[i] = std::min({nums[i], choice1, choice2});
15
16        res = res < dp_max[i] ? dp_max[i] : res;
17    }
18    return res;
19}

第四百一十六题：分割等和子集#

 1bool canPartition(vector<int>& nums)
 2{
 3    int sum = reduce(nums.begin(), nums.end());
 4    if(sum % 2 != 0) return false;
 5    sum /= 2;
 6
 7    int n = nums.size();
 8    std::vector<bool> dp(sum + 1, false);
 9    dp[0] = true;
10    for(int num : nums)
11    {
12        for(int i = sum; num <= i; i--)
13        {
14            if(dp[i - num]) dp[i] = true;
15        }
16        if(dp[sum]) return true;
17    }
18    return dp[sum];
19}

第二百一十三题：打家劫舍 II#

核心是将“环”拆解为“两个线性表”

对于环形的 n 间房屋，可以将其拆解为两个场景：

  • 场景 A：不偷最后一间房。此时可以偷的范围是 nums[0] 到 nums[n-2]
  • 场景 B：不偷第一间房。此时可以偷的范围是 nums[1] 到 nums[n-1]

最后的结果一定是两者中的更大值

rob ()

 1// 这里的辅助函数与上题一样
 2int robRange(std::vector<int>& nums, int start, int end)
 3{
 4    int prev1 = 0, prev2 = 0;
 5    for(int i = start; i < end; i++)
 6    {
 7        int temp = prev2;
 8        prev2 = std::max(prev2, prev1 + nums[i]);
 9        prev1 = temp;
10    }
11    return prev2;
12}
13int rob(vector<int>& nums)
14{
15    int n = nums.size();
16    if(n == 1) return nums[0];
17    if(n == 2) return std::max(nums[0], nums[1]);
18
19    int res1 = robRange(nums, 0, n - 1);
20    int res2 = robRange(nums, 1, n);
21
22    return std::max(res1, res2);
23}
