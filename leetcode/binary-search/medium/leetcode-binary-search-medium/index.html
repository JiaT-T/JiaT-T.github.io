第三十三题：搜索旋转排序数组#

一开始的想法是：先遍历一遍旋转后的数组，分别找到两个各自单调的子数组，之后对这两个数组分别进行二分查找；但这会导致线性的时间复杂度，而不是题目要求的logn

而下面这种方法就是不通过遍历，直接在二分查找中对有序的子数组进行判断

具体实现：

仍然是先定义左右边界（左闭右开），之后进入循环

当mid对应的值恰好与target相等时，则mid就是我们要找的下标

若是不等，则根据当前中点值与最右值得比较结果，对左数组与右数组进行选择

之后再在这两个子数组中进行二分查找

 1int search(vector<int>& nums, int target)
 2{
 3    int left = 0, right = nums.size() - 1;
 4    while(left <= right)
 5    {
 6        int mid = left + (right - left) / 2;
 7        if(nums[mid] == target)
 8            return mid;
 9        else if(nums[left] <= nums[mid])
10        {
11            // 进入左数组
12            if(nums[left] <= target && target < nums[mid])
13                right = mid;
14            else
15                left = mid + 1;
16        }
17        else
18        {
19            //进入右数组
20            if(nums[mid] < target && target <= nums[right])
21                left = mid + 1;
22            else
23                right = mid;
24        }
25    }
26    return -1;
27}

第三十四题：在排序数组中查找元素的第一个和最后一个位置#

lowerBound函数：返回第一个 >= target的数的下标

实现原理：内部是一个while循环，当循环结束时，应当恰好有 left = right 成立，此时right代表 的就是“第一个 >= target的数的下标”————

            - **左阵营 (**`**left**`**)**：在这个索引左边的数，我们确定**全部**都 < target
            - **右阵营 (**`**right**`**)**：在这个索引（包含自身）右边的数，我们确定**全部**都  >= target

又因为target的第一个数恰好满足这个条件，使用lowerBound返回的实际上是target的右边界

之后在主函数中如法炮制，通过求得target+1的首位，再减去1，所得到的就是target的右边界

 1vector<int> searchRange(vector<int>& nums, int target)
 2{
 3    int start = lowerBound(nums, target);
 4    if(start == nums.size() || nums[start] != target)
 5        return {-1, -1};
 6    int end = lowerBound(nums, target + 1) - 1;
 7    return {start, end};
 8}
 9
10// 返回第一个 >= target的数的下标
11int lowerBound(vector<int>& nums, int target)
12{
13    int left = 0, right = nums.size();
14    while(left < right)
15    {
16        int mid = left + (right - left) / 2;
17
18        if(target <= nums[mid])
19            right = mid;
20        else
21            left = mid + 1;
22    }
23    return right;
24}

补充解法：标准库 lower_bound

 1vector<int> searchRange(vector<int>& nums, int target)
 2{
 3    if(nums.empty()) return{-1,-1};
 4    
 5    int start = lower_bound(nums.begin(), nums.end(), target) - nums.begin();
 6    
 7    if(start == nums.size() || nums[start] != target)
 8        return {-1, -1};
 9
10    // 因为这里得到的是第一个 target + 1 的元素的下标
11    // 所以需要减一得到的才是 target 最后一个元素的下标
12    int end = lower_bound(nums.begin(), nums.end(), target + 1) - nums.begin() - 1;
13    return {start, end};
14}

第七十四题：搜索二维矩阵#

解法一：

把二维矩阵转入一维数组，再对这个数组进行二分查找

空间、时间复杂度都为O(M * N)

 1bool searchMatrix(vector<vector<int>>& matrix, int target) 
 2{
 3    std::vector<int> vec;
 4    vec.reserve(matrix.size() * matrix[0].size());
 5    for(auto row : matrix)
 6    {
 7        for(auto element : row)
 8        {
 9            vec.push_back(element);
10        }
11    }
12    return std::binary_search(vec.begin(), vec.end(), target);
13}

<font style="background-color:#FBDE28;">解法二：</font>

核心公式：a[ i ]=matrix [ i / n ][ i mod n ]

实际上并不需要再开辟一个M*N的空间用于存储二维矩阵，可以直接根据一维数组下标与行列的关系找到对应元素

 1bool searchMatrix(vector<vector<int>>& matrix, int target) 
 2{
 3    int rows = matrix.size(), cols = matrix[0].size();
 4    int left = 0, right = rows * cols;
 5    while(left < right)
 6    {
 7        int mid = left + (right - left) / 2;
 8        int x = matrix[mid / cols][mid % cols];
 9        if(target == x) 
10            return true;
11        else if(x < target)
12            left = mid + 1;
13        else if(target < x)
14            right = mid;
15    }
16    return false;
17}

第一百五十三题：寻找旋转排序数组中的最小值#

可以将旋转后的数组视为两个并排的上升台阶，前一部分是“高位台阶”，后一部分是“低位台阶”（只有当旋转nums.size()的整数倍时才会出现前低后高的情况）

高位台阶中的每一级都大于低位台阶的最大级，也就是数组的最后一位；因此，如果 nums.back() < nums[mid] 的话，就可以认为最小值一定在 mid 右边；反之，nums[mid] <= nums.back() 的话，最小值就在 mid 左边 或 nums[mid] 自身就是最小值

根据这一特性，只需要比较 x 和 nums[n−1] 的大小关系，就间接地知道了 x 和数组最小值的位置关系，从而不断地缩小数组最小值所在位置的范围，二分找到数组最小值

 1int findMin(vector<int>& nums)
 2{
 3    int left = 0, right = nums.size();
 4    while(left < right)
 5    {
 6        int mid = left + (right - left) / 2;
 7        if(nums[mid] <= nums.back())
 8            right = mid;
 9        else 
10            left = mid + 1;
11    }
12    return nums[left];
13}
