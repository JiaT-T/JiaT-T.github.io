第五题：最长回文子串#

以一个字符（奇数回文串）或两个字符中间的空隙（偶数回文串）为中心，向左右两端扩散，如果两端字符相同，则继续扩展，并记录当前字符串的起始点

longestPalindrome(）

 1std::pair<int, int> ExpandAroundCenter(const string& s, int left, int right)
 2{
 3    while(left >= 0 && right < s.size() && s[left] == s[right])
 4    {
 5        --left;
 6        ++right;
 7    }
 8    return {left+1, right-1};
 9}
10string longestPalindrome(string s) 
11{
12    int left = 0, right = 0;
13    // 如果输入字符串总长为1，则直接返回该字符串
14    if(s.size() < 2)
15        return s;
16    for(int i = 0; i < s.size(); ++i)
17    {
18        // 奇数回文串
19        auto [left1, right1] = ExpandAroundCenter(s, i, i);
20        // 偶数回文串
21        auto [left2, right2] = ExpandAroundCenter(s, i, i+1);
22        // 判断是奇数还是偶数
23        if(right1 - left1 > right - left)
24        {
25            left = left1;
26            right = right1;
27        }
28        if(right2 - left2 > right - left)
29        {
30            left = left2;
31            right = right2;
32        }
33    }
34    // substr（start，length）：提取特定字符串
35    return s.substr(left, right-left+1);
36}

第七题：整数反转#

通过对输入数字模10得到最低位的数字，然后将输入数字除10，减少输入数字的一位位数，使用此数字进行下一轮循环，直到输入数字最终等于零

注意：在循环过程中，可能出现溢出的情况，因此需要在每一次循环开始前对已经反转的数字进行范围判断，如果已经溢出，则返回零

reverse()

 1int reverse(int x) 
 2    {
 3        int rev = 0;
 4        while(x != 0)
 5        {
 6            if(rev < INT_MIN/10 || rev > INT_MAX/10) return 0;
 7            int d = x % 10;
 8            x /= 10;
 9            rev = rev * 10 + d;
10        }
11        return rev;
12    }

第八题：字符串转换整数 (atoi)#

根据题目的要求逐步实现函数功能：

1.空格：读入字符串并丢弃前导空格–在循环外定义字符串下标，通过while循环判断前面的字符是否为“ ”，如果是，则i加一并进入下一次是否为空格的判断

2.符号：检查下一个字符为“-”还是“+”–通过if判断之后的字符有无符号，有则将sign标记为-1或1（在得出了最后的数字之后乘上），没有则默认为1

3.转换：跳过前置零，直至最后一个字符–这里的零不用单独写一条if语句来判断，可以通过与上一题相同的方法来解决（rev = rev *10 + d）。要注意的是，string使用【】得出的是char类型的字符，而不是整数，需要减去‘0’才能变为int类型

4.舍入：范围 [−231, 231 − 1]–在进行转换之前需要先对上一次的计算结果进行范围判断，如果大于INT_MAX/10或等于INT_MAX/10但是下一位大于7，则直接返回上一次的值（原因：如果上一次的值已经大于了INT_MAX/10，那么经过这次的循环之后，必然会超出范围；又因为最大值是231 − 1，因此在等于INT_MAX的情况下，个位最大值只能是7）

myAtoi()

 1int myAtoi(string s) 
 2    {
 3        int i = 0, result = 0, sign = 1;
 4        while(i < s.size() && s[i] == ' ') i++;
 5        if(i == s.size()) return 0;
 6        if(s[i] == '-' || s[i] == '+')
 7        {
 8            sign = s[i] == '-' ? -1 : 1;
 9            i++;
10        }
11        while(i < s.size() && s[i] >= '0' && s[i] <= '9')
12        {
13            int digit = s[i] - '0';
14            if(result > INT_MAX / 10 || (result == INT_MAX / 10 && digit > 7))
15                return sign == 1 ? INT_MAX : INT_MIN;
16            result = result * 10 + digit;
17            i++;
18        }
19        return result * sign;
20    }

第九题：回文数#

因为负数不可能为回文数，所以直接排除

之后就和之前的题目一样，把反转后的数字再与原数字比较就行

（注意：这里使用int会报错–超出了类型范围，所以改用了unsigned int，因为负数在第一关就被筛掉了）

isPalindrome()

 1bool isPalindrome(int x) 
 2    {
 3        if(x < 0) return false;
 4        unsigned int result = 0, x_copy = x;
 5        while(x != 0)
 6        {
 7            unsigned int a = x % 10;
 8            x /= 10;
 9            result = result * 10 + a;
10        }
11        if(result == x_copy)
12            return true;
13        return false;
14    }

第十四题：最长公共前缀#

思路：从第一个元素的第一个字符开始，先逐渐向后遍历，检查第一个字符是否都相同，然后再进行第二个字符的遍历…..直到出现不同的字符，然后返回公共前缀

结尾的“return strs【0】”代表着：如果循环正常结束，就说明第一个元素就是公共的前缀

longestCommonPrefix（）

 1string longestCommonPrefix(vector<string>& strs)
 2    {
 3        if(strs.empty()) return "";
 4
 5        for(int i = 0; i < strs[0].length(); i++)
 6        {
 7            for(int j = 0; j < strs.size(); j++)
 8            {
 9                if(i == strs[j].length() || strs[j][i] != strs[0][i])
10                    return std::string(strs[0].substr(0, i));
11            }
12        }
13        return strs[0];
14    }
