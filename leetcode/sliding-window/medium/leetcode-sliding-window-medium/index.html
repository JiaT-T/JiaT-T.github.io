第三题：无重复字符的最长子串#

用到的是滑动窗口和unorder_map,

通过两个条件限制窗口范围：

1.当（left，right）存在重复字符时，那么（left，right+1…..right+n）都存在重复数值

2.当（left，right）不存在重复字符时，那么（left+1….left+n，right）都不存在重复字符

因此，（left，right+1…..right+n）与（left+1….left+n，right）都不需要再去进行遍历

核心：用unordered_map记录每个字符的出现次数

11
12    // Key (char): 窗口里的字符 
13
14    // Value (int): 这个字符在当前窗口里出现了几次
15
16    std::unordered_map<char, int> um; 
17
18    
19
20    // 开始滑动窗口。一开始，左右边界都在最左边（索引 0）。
21
22    // right++ 代表窗口的右边缘在不断向右扩展，吞进新的字符。
23

第四百三十八题：找到字符串中所有字母异位词#

思路：从左往右移动窗口，每次移动一格；移动的过程中不断对 left 与 right 指向的元素进行“是否存在于‘p’中“的判断——如果存在，那么对应字符的出现频率减一…..直到最后整个哈希表清零，就可以认为这个窗口中的元素满足条件，将其存入res中

 7
 8    if(ns < np) return {};
 9
10    std::vector<int> res;
11
12
13
14    std::vector<int> count(26, 0);
15
16    for(auto c : p) count[c - 'a']++;
17
18
19
20    int left = 0, right = 0, need = np;
21
22    while(right < ns)
23
24    {
25
26        char c = s[right];
27
28        // 扩大窗口
29
30        if(count[c - 'a'] > 0) need--;
31
32        count[c - 'a']--;
33
34        right++;
35
36
37
38        // 缩小窗口
39
40        if(right - left > np)
41
42        {
43
44            char d = s[left];

第二百零九题：长度最小的子数组#

使用到的是滑动窗口

minSubArrayLen（）

 1int minSubArrayLen(int target, vector<int>& nums)
 2{
 3    int n = nums.size(), sum = 0, left = 0;
 4    // 因为最后的结果输出的是子数组长度
 5    // 所以最大长度肯定不会超过原数组长度 n
 6    int res = n + 1;
 7    // 遍历右边的节点
 8    for(int right = 0; right < n; right++)
 9    {
10        // 首先将右指针指向的节点加到 sum 中
11        sum += nums[right];
12        // 不断缩小窗口
13        while(target <= sum - nums[left])
14        {
15            sum -= nums[left];
16            // 左端点右移
17            left++;
18        }
19        // 此时经过缩小之后，如果 sum 仍然大于等于 target
20        // 就记录一次答案
21        if(target <= sum)
22        {
23            res = std::min(res, right - left + 1);
24        }
25    }
26    return res == n + 1 ? 0 : res;
27}

第一千四百九十三题：删掉一个元素以后全为 1 的最长子数组#

原笔记（代码待复核）

维护一个滑动窗口，窗口内只能存在一个零，同时每一步都动态更新最长子数组的长度

当窗口内零的数量大于一时，将左边界右移，直到零的数量变为一

longestSubarray（）

 1int longestSubarray(vector<int>& nums)
 2{
 3    int left = 0, zero_count = 0, res = 0;
 4
 5    for(int right = 0; right < nums.size(); right++)
 6    {
 7        if(nums[right] == 0)
 8            zero_count++;
 9
10        while(1 < zero_count)
11        {
12            if(nums[left] == 0)
13                zero_count--;
14
15            left++;
16        }
17
18        res = std::max(right - left + 1 - 1,);
19    }
20    return res;
21}
