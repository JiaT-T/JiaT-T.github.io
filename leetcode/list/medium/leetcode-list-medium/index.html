第二题：两数相加#

首先明确思路，逐节点的将l1和l2相加，如果遇到需要进位的情况，就单独将所进的位数保存起来，并加到下一次的sum中去，然后在同一次循环中构造好相加后的链表

 1ListNode* addTwoNumbers(ListNode* l1, ListNode* l2) 
 2{
 3    ListNode dummy(0);
 4    ListNode* curr = &dummy;
 5
 6    int carry = 0;
 7    while(l1 || l2 || carry != 0)
 8    {
 9        int sum = carry;
10        if(l1)
11        {
12            sum += l1->val;
13            l1 = l1->next;
14        }
15        if(l2)
16        {
17            sum += l2->val;
18            l2 = l2->next;
19        }
20
21        // 进位
22        carry = sum / 10;
23        int digit = sum % 10;
24        curr->next = new ListNode(digit);
25        curr = curr->next;
26    }
27    return dummy.next;
28}

第十九题：删除链表的倒数第 N 个结点#

使用的是双指针

定义左指针left和右指针right，初始都先指向头结点的前一个结点（哨兵节点），然后先将right指针向后移动n的距离，这样当right指针遍历到尾节点时，left指针恰好处于right指针后n个位置，也就是倒数第n个节点。

到达目标位置之后，先将需要删除的节点保存在一个临时变量中，避免内存泄漏，再将上一个节点的指向改为当前节点的下一个节点，最后delete当前节点，并返回头节点

 1ListNode* removeNthFromEnd(ListNode* head, int n) 
 2    {
 3        ListNode dummyNode(0, head);
 4        ListNode* left = &dummyNode;
 5        ListNode* right = &dummyNode;
 6        for(int i = 0; i < n; i++)
 7        {
 8            right = right->next;
 9        }
10
11        while(right->next != nullptr)
12        {
13            right = right->next;
14            left  = left->next;
15        }
16        auto temp = left->next;
17        left->next = left->next->next;
18        delete temp;
19        return dummyNode.next;
20    }

第二十四题：两两交换链表中的节点#

使用的是迭代

就像之前写过的大部分链表的题目一样，要创建一个哨兵节点（前置节点）

首先哨兵节点指向第一个节点，之后进入循环，前置节点指向第二个节点，第一个节点指向第三个节点，最后让第二个节点指向原来的第一个节点，将前置节点指向此时的第二个节点，进入下一次循环

 1ListNode* swapPairs(ListNode* head)
 2    {
 3        if( !head || !head->next ) return head;
 4        ListNode header1(0, head);
 5        ListNode* prev = &header1;
 6
 7        while(prev->next && prev->next->next)
 8        {
 9            auto node1 = prev->next;
10            auto node2 = prev->next->next;
11
12            prev->next = node2;
13            node1->next = node2->next;
14            node2->next = node1;
15
16            prev = node1;
17        }
18        
19        return header1.next;
20    }

补充解法：递归交换相邻节点

1ListNode* swapPairs(ListNode* head)
2{
3    if(head == nullptr || head->next == nullptr) return head;
4
5    ListNode* newHead = head->next;
6    head->next = swapPairs(newHead->next);
7    newHead->next = head;
8    return newHead;
9}

第二十六题：删除有序数组中的重复项#

使用的是双指针

这里如果使用最原始的方法：如果当前元素与上一个相同则删除(erase），会导致O(n^2)的时间复杂度——————erase（）会将删除元素后面的元素向前移动

而这里，我们定义了两个指针，一个慢指针（k），一个快指针（i）；将两个指针对应的值进行比较，如果不同，就将慢指针后移，同时将慢指针所指元素覆盖为当前元素

在这个方法中，我们并没有真正执行“删除”操作，而是对数组进行了重新排列，将重复的元素放到数组末尾，因为最终的返回值是有效的数字个数，因此末尾的区域也就会变成垃圾数据，不需要再去关心它们

 1int removeDuplicates(vector<int>& nums)
 2    {
 3        if(nums.empty()) return 0;
 4
 5        int k = 0;
 6        for(int i = 1; i < nums.size(); i++)
 7        {
 8            if(nums[i] != nums[k])
 9            {
10                k++;
11                nums[k] = nums[i];
12            }
13        }
14        return k + 1;
15    }

第一百三十八题：随机链表的复制#

使用到的是哈希表

思路：因为第一次遍历复制各个结点的时候，是不知道后面的节点的，因此一次遍历无法将random元素对应上去，所以一共需要两次遍历：第一次复制所有节点并并对应的random与当前节点绑定，第二次将当前节点的random元素指向对应的成员

 1Node* copyRandomList(Node* head)
 2    {
 3        if(head == nullptr) return nullptr;
 4        Node* curr = head;
 5        std::unordered_map<Node*, Node*> map;
 6
 7        while(curr != nullptr)
 8        {
 9            map[curr] = new Node(curr->val);
10            curr = curr->next;
11        }
12
13        curr = head;
14        while(curr != nullptr)
15        {
16            map[curr]->next = map[curr->next];
17            map[curr]->random = map[curr->random];
18            curr = curr->next;
19        }
20        return map[head];
21    }

第一百四十二题：环形链表 II#

如图，环外的长度为a，slow指针进入环内走了b才与fast相遇，fast走完了n圈，也就是n（b+c）+ b的距离

根据两者相遇时的时间相同，可以得到等式：a+(n+1)b+nc=2(a+b)⟹a=c+(n−1)(b+c)

当n等于1时，a=c；此时如果放置一个指针从head处向后移动，同时另一个指针从slow与fast相遇的地方以相同的速度沿着c移动，那么两者最终会在环的入口处相遇；至于为什么不考虑n，而是直接取n为1，是因为n仅仅代表着相遇处的指针多走的圈数，最后两者还是会在入口相遇

 1ListNode *detectCycle(ListNode *head)
 2    {
 3        if(head == nullptr || head->next == nullptr) return nullptr;
 4        ListNode *slow = head, *fast = head, *p1 = head;
 5        while(fast != nullptr)
 6        {
 7            slow = slow->next;
 8            if(fast->next == nullptr) return nullptr;
 9            fast = fast->next->next;
10            if(slow == fast)
11            {
12                while(p1 != slow)
13                {
14                    p1 = p1->next;
15                    slow = slow->next;
16                }
17                return p1;
18            }
19        }
20        return nullptr;
21    }

第一百四十八题：排序链表#

解法一：归并排序（分治）

时间复杂度：O(nlogn)，空间复杂度：O(logn)

从上至下将链表拆分为长度为一的单链表，然后先对长度为1的链表排序，合并两个链表；

再对长度为2的两个链表排序，之后合并….以此类推，每次排序并合并一半链表，最终就可以得到有序的链表

具体实现：

mergeSort（）：

在头部定义一个哨兵节点，然后遍历比较left与right的值，如果left更小，就将当前left节点接到哨兵节点后面，并将left向后移动一位，继续比较（right同理）；最后当left或者right其中一个为空，也就是该子链表遍历完成时，就直接将另一个链表接到末尾，此时返回的哨兵节点的next就是排序后的链表的头节点

sortList（）：
在主函数中，需要不断地将链表分为两半（通过递归调用），之后每一层递归都会调用mergeSort函数对当前分割出来的两个链表进行排序，直到最后合成回初始的链表

解法二：归并排序（迭代）

 1class Solution
 2{
 3public:
 4    ListNode* mergeSort(ListNode* left, ListNode* right)
 5    {
 6        ListNode* dummyNode = new ListNode(0);
 7        ListNode* trail = dummyNode;
 8        while(left && right)
 9        {
10            if(left->val < right->val)
11            {
12                trail->next = left;
13                left = left->next;
14            }
15            else
16            {
17                trail->next = right;
18                right = right->next;
19            }
20            trail = trail->next;
21        }
22        if(left)
23            trail->next = left;
24        else
25            trail->next = right;
26
27        return dummyNode->next;
28    }
29
30    ListNode* sortList(ListNode* head)
31    {
32        if(!head || !head->next) return head;
33
34        ListNode *slow = head, *fast = head->next;
35        while(fast && fast->next)
36        {
37            slow = slow->next;
38            fast = fast->next->next;
39        }
40        ListNode *second = slow->next;
41        slow->next = nullptr;
42        ListNode *first = head;
43
44        first = sortList(first);
45        second = sortList(second);
46
47        return mergeSort(first, second);
48    }

第一百四十六题：LRU 缓存#

使用到的是哈希表和链表（重点是链表迭代器）

这题难点在于“逐出最久未使用的关键字”，首先明确思路：既然要求常数时间的复杂度，那么就一定会要用到哈希表（查找），但是又要求有一个数据结构可以存储元素使用的顺序，并且改变顺序时也要是O(1)的时间复杂度，那么就也要使用到链表（通过调用 Splice函数 可以改变迭代器位置，从而在常数时间内实现顺序的改变）

但是如何将哈希表与链表结合起来？答：将value和iterator绑定在一起，这样就通过key就既可以得到value的值，又可以实现iterator的移动

具体实现：

首先拿到最大容量，避免后续多次函数调用产生的开销；

然后开始定义 get 函数：

- 如果哈希表内能够找到对应的key，那么就认为这个元素被访问了一次，因此也就需要将其放在链表的尾部，这里可以通过key在哈希表中找到对应的iterator
- splice（）函数的语法之一（移动单个节点）：
                * **void splice(const_iterator pos, list& other, const_iterator it);**
-  将 `other` 链表中由 `it` 指向的那个元素剪切到 `this` 链表的 `pos` 位置

最后实现 put 函数：

- 这里有两种情况需要处理：1.当前key已经存在	2.容量已满
- 1.key重复：
    * 意味着需要覆写之前的value，将其移至list尾部，这里还是使用到splice（）
- 2.容量已满：
    * 此时需要删除头节点，直接pop_front()即可；同时也要同步删除哈希表中对应的元素

最后将新插入的元素添加到两个容器即可

 1class LRUCache
 2{
 3public:
 4    LRUCache(int capacity) : capacity(capacity)
 5    {
 6        cache.reserve(capacity);
 7    }
 8    
 9    int get(int key)
10    {
11        if(cache.contains(key))
12        {
13            auto it = cache.find(key);
14            order.splice(order.end(), order, it->second.second);
15            return it->second.first;
16        }
17        else return -1;
18    }
19    
20    void put(int key, int value)
21    {
22        auto it = cache.find(key);
23        if(it != cache.end()) // 如果value已经存在，则更新
24        {
25            it->second.first = value;
26            order.splice(order.end(), order, it->second.second);
27            return;
28        }
29        if(cache.size() >= capacity) // 处理超出容量情况
30        {
31            cache.erase(order.front());
32            order.pop_front();
33        }
34    
35        order.push_back(key);
36        cache[key] = {value, std::prev(order.end())};
37    }
38
39private :
40    int capacity;
41    std::unordered_map<int, std::pair<int, std::list<int>::iterator>> cache;  // 键，值，迭代器
42    std::list<int> order; 
43};

第九十二题：反转链表 II#

核心思想：将 left 的前一个节点指向 right，将 left 指向 right 的下一个节点

所以一共需要找到三个节点的位置，这里使用的是两个遍历，分别定位 left 的前一个节点 / left节点和 right 的下一个节点

reverseBetween（）

 1ListNode* reverse(ListNode* prev, ListNode* curr, ListNode* last)
 2{
 3    if(curr == last)
 4    {
 5        return prev;
 6    }
 7    ListNode* temp = curr->next;
 8    curr->next = prev;
 9    return reverse(curr, temp, last);
10}
11ListNode* reverseBetween(ListNode* head, int left, int right)
12{
13    ListNode* dummy = new ListNode(0);
14    dummy->next = head;
15    ListNode* pre = dummy;
16
17    // 找到 pre（left 的前一个节点）
18    for(int i = 1; i < left; i++)
19    {
20        pre = pre->next;
21    }
22    // 通过 pre 可以定位到 left
23    ListNode* left_node = pre->next;
24
25    // 找到 right 的下一个节点
26    ListNode* last = left_node;
27    for(int i = left; i <= right; i++)
28    {
29        last = last->next;
30    }
31
32    // 将【left，right】区间翻转
33    // 这里的 new_head 就是之前的 right
34    ListNode* new_head = reverse(nullptr, left_node, last);
35    pre->next = new_head;
36    left_node->next = last;
37
38    return dummy->next;
39}

第一百零九题：有序链表转换二叉搜索树#

使用到了递归与双指针

sortedListToBST（）

 1TreeNode* sortedListToBST(ListNode* head)
 2{
 3    if(head == nullptr) return nullptr;
 4    if(head->next == nullptr) return new TreeNode(head->val);
 5
 6    // 找出链表的中点
 7    // 循环结束时，slow 即为树的根节点
 8    // 同时 slow 左边的链表为左子树，slow 右边为右子树
 9    ListNode *slow = head, *fast = head, *prev = nullptr;
10    while(fast != nullptr && fast->next != nullptr)
11    {
12        prev = slow;
13        slow = slow->next;
14        fast = fast->next->next;
15    }
16
17    prev->next = nullptr;
18    TreeNode* root = new TreeNode(slow->val);
19    root->left = sortedListToBST(head);
20    root->right = sortedListToBST(slow->next);
21    return root;
22}
