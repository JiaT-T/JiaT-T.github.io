第二十五题：K 个一组翻转链表#

 1ListNode* reverseKGroup(ListNode* head, int k)
 2{
 3    // 统计节点个数
 4    int n = 0;
 5    for(ListNode* node = head; node; node = node->next)
 6    {
 7        n++;
 8    }
 9
10    ListNode dummy(0, head);
11    ListNode* trailer = &dummy;
12    ListNode* curr = head;
13    ListNode* prev = nullptr;
14
15    //外层循环：确保每次只翻转 k 个节点
16    for(; k <= n; n -= k)
17    {
18        // 内层循环：执行翻转的操作
19        for(int i = 0; i < k; i++)
20        {
21            ListNode* temp = curr->next;
22            curr->next = prev;
23            prev = curr;
24            curr = temp;
25        }
26
27        // 将翻转后的节点组与其他节点进行连接
28        /* trailer->next 原本指向的是翻转链表的第一个节点
29           经过翻转之后，这个节点变成了最后一个节点 */
30        ListNode* nxt = trailer->next;
31        trailer->next = prev;
32        nxt->next = curr;
33        // 将 trailer 移动到下一组的前一个节点
34        trailer = nxt;
35    }
36    return dummy.next;
37}

第二十三题：合并 K 个升序链表#

参考：https://leetcode.cn/problems/merge-k-sorted-lists/solutions/2384305/liang-chong-fang-fa-zui-xiao-dui-fen-zhi-zbzx/?envType=problem-list-v2&envId=91oI3WTD

首先明确思路：对于第一个插入的节点，一定是某一个链表的头节点，而第二个节点，不是当前节点的下一个节点，就是其他链表的头节点…此时需要有一个数据结构，能够找到并去除最小节点，同时还要能插入新节点——这里使用的是“最小堆”

首先定义初始状态——将三个头节点存入堆中，然后找出最小节点作为头节点；接着判断被删去的节点是否存在下一个节点，如果有，就将其存入堆中，之后进行进行相同的判断，直到堆为空

mergeKLists（）

 1ListNode* mergeKLists(vector<ListNode*>& lists) 
 2{
 3    auto cmp = [](ListNode* a, ListNode* b)
 4    {
 5        return a->val > b -> val;
 6    };
 7    std::priority_queue<ListNode*, std::vector<ListNode*>, decltype(cmp)> less_heap;
 8
 9    for(auto head : lists)
10    {
11        if(head != nullptr)
12            less_heap.push(head);
13    }
14
15    ListNode dummy(0);
16    ListNode* head = &dummy;
17    while(!less_heap.empty())
18    {
19        auto node = less_heap.top();
20        less_heap.pop();
21        if(node->next != nullptr)
22        {
23            less_heap.push(node->next);
24        }
25        head->next = node;
26        head = head->next;
27    }
28    return dummy.next;
29}
