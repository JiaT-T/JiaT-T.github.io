第五十三题：最大子数组和#

核心判断条件：

如果前一段子序列之和与当前元素相加之后，还没有当前元素本身大，那么就直接从当前元素开始重新计算

具体实现：

首先定义两个和，一个用于记录目前为止的最大和（max_val），一个用于在循环中进行判断（curr_val）

之后进入循环，通过上述判断条件对当前最大和进行更新，再用当前最大和与之前保持的最大和进行比较

int maxSubArray(vector<int>& nums)
{
    int curr_val = nums[0];
    int max_val = nums[0];

    for(int i = 1; i < nums.size(); i++)
    {
        if(curr_val + nums[i] < nums[i])
            curr_val = nums[i];
        else
            curr_val = curr_val + nums[i];
        
        if(curr_val > max_val)
            max_val = curr_val;
    }
    return max_val;
}

第五十六题：合并区间#

思路：

难点在于“如何对重叠区间进行合并”，这里选用的判断条件是—如果当前区间左边界小于结果数组尾部区间的右边界，则选取两者中更大的右边界进行合并

具体实现：

首先以左边界为基准对原数组进行了排序，这样就能从左往右更好地判断是否重叠

这里使用到了lambda表达式，它的语法是：

// [捕获列表](参数列表) -> 返回值类型 { 函数体 }

auto my_func = [ ](int a, int b) { return a + b; };

但实际上，返回值类型通常可以省略，让编译器自己去猜。所以最常用的长这样：

[] (int a, int b) { return a + b; }

至于这里为什么是直接在res中进行修改，这是因为可以避免多次push_back的开销

vector<vector<int>> merge(vector<vector<int>>& intervals)
{
    if(intervals.empty()) return {};
    std::sort(intervals.begin(), intervals.end(), [](const vector<int>& a, const vector<int>& b){return a[0] < b[0];});

    vector<vector<int>> res{intervals[0]};

    for(int i = 1; i < intervals.size(); i++)
    {
        // 当前元素左边界小于等于上一个区间右边界 -->  发生重合！
        if(intervals[i][0] <= res.back()[1]) 
            // 取更大的有边界合并
            res.back()[1] = std::max(res.back()[1], intervals[i][1]);
        else
            res.push_back(intervals[i]);
    }
    return res;
}

第一百八十九题：轮转数组#

解法一：

思路比较简单，仅仅是将移动后的元素存放到另一个数组

具体实现：

因为轮转的特性，每当移动的次数是数组大小的整数倍时，就相当于完全没有变化，使所以直接返回

之后再通过一轮遍历，将原数组中的元素进行移动即可

// 解法一：
void rotate(vector<int>& nums, int k)
{
    int sz = nums.size();
    if(k % sz == 0) return;

    std::vector<int> vec(sz, 0);
    for(int i = 0; i < sz; i++)
    {
        int index = (i + k) % sz;
        vec[index] = nums[i];
    }
    nums = vec;
}

思路如下：

假设现在有一个数组[1,2,3,4,5,6,7]，需要变换成[5,6,7,1,2,3,4]

可以将转换后的数组视为：[5,6,7] + [1,2,3,4]

首先要确保的是[5,6,7]在[1,2,3,4]前面，这可以通过翻转整个数组得到——> [7,6,5,4,3,2,1]

之后就只需要对[7,6,5] 和 [4,3,2,1]两个子数组进行翻转就可以得到最终的结果

如此，即可将复杂的移动操作转换为反转操作

void rotate(vector<int>& nums, int k)
{
    k %= nums.size();
    ranges::reverse(nums);
    std::reverse(nums.begin(), nums.begin() + k);
    std::reverse(nums.begin() + k, nums.end());
}

第二百三十八题：除了自身以外数组的乘积#

思路如下：

因为不能使用除法——通过一次遍历计算整个数组的乘积，之后再进行一次遍历，每次除以当前元素的值

同时要求时间复杂度是O(n)，空间复杂度要求是O(1)，但是输出的数组不计入额外空间，所以需要直接对输出数组进行操作；

可以先通过一次遍历计算出左边的乘积，再从后往前进行一次遍历，将右边的乘积再乘到res的当前元素上去，这样最终得到的res数组就是除自身外的元素的乘积

注：这里需要提前预留好res的空间，而不是在循环中每次都调用push_back

vector<int> productExceptSelf(vector<int>& nums)
{
    const int sz = nums.size();
    std::vector<int> res(sz);
    res[0] = 1;

    int temp = 1;
    for(int i = 0; i < sz; i++)
    {
        res[i] = temp;
        temp *= nums[i];
    }

    temp = 1;
    for(int j = sz - 1; 0 <= j; j--)
    {
        res[j] *= temp;
        temp *= nums[j];
    }

    return res;
}
