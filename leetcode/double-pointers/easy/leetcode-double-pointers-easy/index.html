第二十七题：移除元素#

解法一：

  1. 先对整个数组进行排序，将相同元素堆到一起
  2. 然后通过两次遍历找到重复元素的起始、终止下标
  3. 最后一键清除

removeElement（）

 1int removeElement(vector<int>& nums, int val) 
 2{
 3    std::sort(nums.begin(), nums.end());
 4    int start = 0;
 5    while(start < nums.size() && nums[start] != val)
 6    {
 7        start++;
 8    }
 9    if(start == nums.size()) return nums.size();
10    int end = start;
11    while(end < nums.size() && nums[end] == val)
12    {
13        end++;
14    }
15
16    nums.erase(nums.begin() + start, nums.begin() + end);
17    return nums.size();
18}

解法二：
使用到的是快慢指针

快指针负责遍历整个数组，慢指针负责指向下一个“不等于 val”的元素的位置

如果 fast 指向的不是 val，就将这个元素放到前面去，最后 slow 前面的元素代表的就全是“不等于 val”的数字

removeElement（）

 1int removeElement(vector<int>& nums, int val) 
 2{
 3    int slow = 0, fast = 0;
 4    for(; fast < nums.size(); fast++)
 5    {
 6        if(nums[fast] != val)
 7        {
 8            nums[slow] = nums[fast];
 9            slow++;
10        }
11    }
12    return slow;
13}

第一百二十五题：验证回文串#

isPalindrome（）

 1bool isPalindrome(string s)
 2{
 3    if(s.size() == 1) return true;
 4    // 定义左右指针
 5    int left = 0, right = s.size() - 1;
 6    // 不需要考虑 left = right 的情况
 7    // 因为中间多一个字符的情况可以直接当作偶数串处理
 8    while(left < right)
 9    {
10        // 拿到左边的数字或字符
11        while(left < right && !isalnum(s[left]))
12        {
13            left++;
14        }
15
16        // 拿到右边的数字或字符
17        while(left < right && !isalnum(s[right]))
18        {
19            right--;
20        }
21
22        // 如果是大写就将其转换为小写
23        // 如果已经是小写或数字就原样返回
24        if(std::tolower(s[left]) != std::tolower(s[right])) return false;
25        // 移动指针
26        left++;right--;
27    }
28    return true;
29}

第二百八十三题：移动零#

思路：使用两个指针，一个从前往后对数组进行遍历，另一个始终指向前端的非零元素；只要指针 i 指向的元素非零，就将指针 k 当前指向的元素赋值为 num[i] ，最后再将指针 k 后面的元素全部置为零即可

moveZeroes（）

 1void moveZeroes(vector<int>& nums) 
 2{
 3    int k = 0;
 4    for(int i = 0; i < nums.size(); i++)
 5    {
 6        if(nums[i] != 0)
 7        {
 8            nums[k] = nums[i];
 9            k++;
10        }
11    }
12    for(int j = k; j < nums.size(); j++)
13    {
14        nums[j] = 0;
15    }
16}
